# Intelligent Software Defect Tracking System

A machine learning based web application for bug tracking, defect analysis, severity prediction, priority prediction, and resolution assistance.

## Features
- Bug Analytics Dashboard
- Bug Life Cycle Visualization
- Machine Learning Models
- Severity Prediction
- Priority Prediction
- AI Resolution Assistance

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly
